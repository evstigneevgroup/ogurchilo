# Огурчило 🥒

Гипер-казуальная веб-игра: на экране огурец — тапами счищаешь с него шкурку, рука обхватывает огурец и ходит вверх-вниз. Раунд — 30 секунд. Соперничаешь с друзьями и случайными игроками, за цели получаешь промикоды и подарки от партнёрской сети.

Это рабочий прототип: ядро игры полностью играбельно, социальные и призовые механики подключены через абстракцию `Platform` (в демо — локальные заглушки).

## Запуск

Любой статический сервер (или просто открыть файл):

```bash
cd ogurchilo
python3 -m http.server 8471
# http://127.0.0.1:8471
```

Наружных зависимостей нет (шрифты системные, графика и звук — процедурные). Управление: тап/клик по канвасу; пауза — ⏸; звук — 🔊/🔇; прогресс хранится в `localStorage`.

## Механика

- Тап → рука делает рывок вверх-вниз, с границы чистки летят обрывки шкурки, огурец «сплющивается», хруст (WebAudio).
- Шкурка уходит сверху вниз; каждые ~19 тапов огурец чист, выпадает новый (+60 очков).
- Тапы чаще 700 мс строят комбо до ×12 → до 3.4× очков; с каждым новым огурцом в раунде чистка идёт чуть медленнее.
- По итогам раунда: место среди случайных соперников, рекорд, «+, после достижения целей — бейдж на кнопке «Призы».
- Призы: 3/10/25/50 очищенных огурцов за всё время → промикод (жмёшь «Забрать» — код копируется).

## Почему сначала Telegram Mini App

Сравнение площадок под эту механику (тап-кликер + друзья + призы):

| Критерий | Telegram | VK | Одноклассники |
|---|---|---|---|
| Скорость запуска | максимум: бот + ссылка, без модерации каталога | создание приложения + модерация | создание приложения + модерация |
| Виральным мехканал | чаты, шаринг ссылок, подарки-звёзды | лентa/виджеты, каталог игр | лента «Близко», поздравления |
| Аудитория под призы | молодёжь, быстрые всплески | широкий охват, зрелые кликер-механики | 35+, лучше всего конвертит «подарки/промики» |
| Друзья в API | через контакты/чаты | есть (`VKWebAppGetFriends`) | есть |

Решение: **ядро одно — HTML5; запускаемся в Telegram Mini App**, VK и OK — следующие сборки. Абстракция `platform.js` уже сейчас переключается по наличию глобалов (`Telegram.WebApp`, `vkBridge`, `FAPI`), VK/OK останутся фолбэком веб-шаринга. OK добавляем как вторую площадку, когда появится партнёрская сеть с промиками — её аудитория для призов целевая.

## Структура

```
index.html        — разметка экранов/оверлеев
css/style.css     — палитра (крем + зелёный), чанки UI
js/platform.js    — абстракция площадки: TG/VK/OK/веб, шаринг, хаптика
js/storage.js     — localStorage-состояние (v1)
js/leaderboards.js— демо-генерация друзей/соперников (seed от минуты)
js/prizes.js      — конфиг ступеней призов (формат как у будущего API)
js/game.js        — ядро: canvas, огурец, рука, частицы, звук, watchdog rAF
js/ui.js          — экраны, HUD, рейтинги, призы, тосты
js/main.js        — бутстрап
```

## Промокоды: как работает выдача (боевая схема)

1. Игрок в мини-аппе достигает цели (3/10/25/50 очищенных огурцов) → жмёт «Забрать».
2. Игра открывает чат бота глубокой ссылкой `t.me/ogurchilo_bot?start=claim_<приз>_<прогресс>`.
3. Бот (`ogurchilo/bot/bot.py`, крутится на VPS 89.208.106.212 в systemd как `ogurchilo-bot`)
   берёт свободный код из пула `/opt/ogurchilo-bot/codes.json` и присылает его сообщением в чат.
4. Повторное «Забрать» того же приза возвращает твой же код. Пул пополняется правкой `codes.json` + `systemctl restart ogurchilo-bot`.

Управление пулом:
```bash
ssh root@89.208.106.212
nano /opt/ogurchilo-bot/codes.json    # {"coffee": ["КОД1", ...], "food": [...], ...}
systemctl restart ogurchilo-bot
```
Остатки пула — командой `/codes` в чате с ботом.

Важно: `WebApp.sendData` из мини-аппа, открытого через кнопку меню, Telegram молча игнорирует — поэтому используется глубокая ссылка. Прогресс игрока синхронизируется между устройствами через `WebApp.CloudStorage` (на клиентах, где он есть).

## Дорожная карта до бойницы

1. **Бэкенд**: сервер-валидация раундов (античит: сервер-валидация тап-раундов, rate-limit), реальные рейтинги «друзей» через API площадки.
2. **Партнёрская сеть**: подача заявки на Mitgo/Admitad сделана; после модерации — импортёр купонного фида (`client_id/secret` → `/opt/ogurchilo-bot/codes.json` по расписанию).
3. **Обёртки**: Telegram WebApp SDK подключён (локальная копия SDK в `js/telegram-web-app.js` — независимость от доступности telegram.org); VK Bridge и ODKL — тем же `Platform`.
4. Прод: звёзды/монетизация, ивенты («тропа огурцов»), ежедневные задания.
